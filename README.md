Beyond Identity is a zero-trust passwordless authentication platform that eliminates passwords by binding credentials to physical devices using platform authenticators and cryptographic passkeys. The platform provides REST APIs for managing tenants, realms, identities, and device-bound credentials across workforce and customer identity use cases. Beyond Identity supports continuous risk assessment with device security signals, policy enforcement, and just-in-time access controls. The platform integrates with SCIM, OIDC, and OAuth 2.0 standards and offers multi-region deployment including US, EU, and FedRAMP environments.

**Areas:** Authentication · Passwordless · Zero Trust · Identity · Passkeys · MFA · Device Security · OpenID Connect · SCIM · Identity Federation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
